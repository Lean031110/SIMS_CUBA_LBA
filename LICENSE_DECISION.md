# Decisión de licencia pendiente

El repositorio es público, pero eso no concede permiso para reutilizar su contenido. El propietario debe decidir si el código será propietario, open source o una mezcla con licencias por componente.

Hasta que se decida:
- No añadir una licencia abierta por defecto.
- No declarar los assets como reutilizables.
- Revisar la licencia de cada dependencia y recurso.
- Mantener atribuciones y avisos obligatorios.
