# Política de seguridad

Este repositorio está en investigación/preproducción y aún no ofrece un servicio público de juego.

No publiques exploits, credenciales, tokens, datos de jugadores ni detalles explotables de terceros en Issues. Para reportes privados usa un canal privado indicado por el propietario. No realices escaneos ni pruebas sobre CubitaLife; este proyecto no está autorizado para evaluar su infraestructura.

Antes de beta pública se añadirá canal de reporte, plazo de respuesta, política de divulgación y proceso de incidentes.
