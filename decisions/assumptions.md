# Supuestos controlados

- Android nativo es la primera plataforma objetivo porque el usuario lo ha pedido explícitamente.
- Godot 4.x + GDScript es una recomendación provisional a validar mediante prototipo.
- Cloudflare Workers + Durable Objects es candidato de piloto, no hosting aprobado para lanzamiento.
- Los nombres de UI visibles son evidencia de labels, no evidencia de reglas.
- Todo contenido, código, modelo y arte del juego nuevo debe ser original o contar con licencia.
- La edad, monetización, licencia, marca y capacidades de concurrencia están pendientes de decisión.
- No hay build ni servidor desplegado.
