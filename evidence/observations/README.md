# Observaciones

Guardar aquí fichas de una interacción por archivo. Nombrar con ID y fecha. No almacenar capturas con información privada o de terceros sin consentimiento.

Cada ficha debe:
- indicar la procedencia del material, dispositivo/plataforma y fecha;
- separar CONFIRMED_UI, OBSERVED_COPY y NOT_TESTED;
- registrar timestamps para vídeos;
- anotar precondición, acción, resultado visible, cambios de estado y persistencia;
- no incluir contraseñas, correos, tokens, saldos privados ni identificadores de otros jugadores;
- distinguir prueba visual de prueba funcional;
- enlazar fuentes externas en evidence/source-register.md.
