# Observaciones UI/UX públicas

## Observado
La portada muestra un HUD con nombre de personaje de muestra, cartera CUP, necesidades Energía/Comida/Humor/Salud, navegación Explorar/Trabajo/Estudiar/Mi casa/Viajar por Cuba, campo de chat y accesos Mi celular/El barrio/Ir a casa/Comer. También muestra controles de cámara.

## Implicación Android
No trasladar controles desktop literalmente. Diseñar joystick, cámara táctil, botón contextual, navegación compacta, targets grandes y HUD escalable. Usar estados de carga/error/reconexión y accesibilidad.

## No inferir
No se ha comprobado jerarquía real de pantallas, animaciones, colores, navegación interna, accesibilidad, confirmaciones, respuesta del chat ni cambios de escena. Mantener diseño original en vez de calcar composición protegida.
