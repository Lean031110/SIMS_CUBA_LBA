# Análisis de Android como plataforma objetivo

La referencia pública consultada informa que su vista previa no está disponible en ese dispositivo; no demuestra que exista ni cómo funcione una app Android dedicada. SIMS CUBA LBA sí tendrá Android nativo como plataforma primaria.

## Requisitos propios
- Instalación APK para QA y AAB cuando se decida distribución.
- Controles touch-first y soporte para múltiples relaciones de aspecto.
- Pausa/reanudación y reconexión tras suspensión del proceso.
- Gestión de memoria, batería, temperatura, almacenamiento y datos móviles.
- Permisos mínimos y privacidad.
- Pruebas en teléfono real, no solo emulador.
