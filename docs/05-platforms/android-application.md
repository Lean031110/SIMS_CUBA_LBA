# Aplicación Android

## Objetivo
Aplicación instalable nativa, desarrollada inicialmente con Godot 4.x y GDScript como opción provisional. No asumir que una WebView es suficiente para el mundo 3D.

## Experiencia
Pantallas táctiles, entrada por joystick y gestos, HUD escalable, accesibilidad y configuración de gráficos. La app debe tolerar interrupción, suspensión y cambios de red.

## Calidad
Medir en dispositivos físicos: FPS sostenido, RAM, tamaño, carga, temperatura, consumo y estabilidad. Incluir dispositivos modestos y gama media.

## Release
APK debug para pruebas; AAB firmado solo tras aprobar publicación. Keystore y claves fuera del repositorio.
