# Seguridad del cliente y backend

- Autenticación segura; almacenar hashes con algoritmo moderno y parámetros adecuados o delegar a proveedor confiable.
- Tokens de acceso de corta duración y renovación protegida.
- Validación de autorización en servidor en cada operación.
- Rate limiting, validación de payload y protección contra replay.
- Secretos fuera de código, logs y artefactos.
- Cifrado en tránsito y en reposo cuando corresponda.
- Ledger auditable y protección contra duplicación de recompensas.
- Moderación, bloqueo, silenciamiento, reporte y controles de edad/privacidad.
- Backups probados; proceso de respuesta a incidentes.
- No registrar contraseñas, tokens, datos de pago ni chats privados completos.

La política final de datos y edad debe aprobarse antes de una beta abierta.
