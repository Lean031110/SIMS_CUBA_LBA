# Comparación de motores

| Motor | Ventajas | Costes/riesgos | Evaluación |
|---|---|---|---|
| Godot 4.x | Open source, GDScript, Android export, ligero | Networking 3D y ecosistema menos integrado que grandes motores | Recomendado para prototipo |
| Unity | Ecosistema, herramientas móviles, plugins y talento | Licencia y planes deben comprobarse; dependencias | Alternativa fuerte |
| Unreal | Gráficos avanzados y herramientas 3D | Peso, requisitos y complejidad altos para equipo pequeño y gama baja | No para primer MVP |
| Three.js/Babylon + wrapper | Flujo web y despliegue fácil | Wrapper no equivale a motor nativo | Solo si se decide web-first |

Decisión actual: Godot 4.x + GDScript provisional. La decisión final requiere benchmark Android real.
