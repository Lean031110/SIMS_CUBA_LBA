# Roles de agentes IA

## Research Agent
Recopila fuentes públicas, registra evidencia y actualiza gaps. No programa ni asume comportamiento no observado.

## Product/Game Designer
Convierte funciones verificadas en flujos, reglas, criterios de aceptación y GDD. Separa paridad de mejoras.

## Godot Android Engineer
Construye escenas, controles táctiles, assets originales, export y profiling. Debe probar en dispositivo.

## Backend/Realtime Engineer
Diseña API, autenticación, zonas, realtime, persistencia, ledger, rate limits y observabilidad.

## QA Agent
Diseña casos reproducibles, automatiza tests, comprueba Android y documenta resultados reales.

## Security/Privacy Reviewer
Revisa auth, datos personales, chat, moderación, economía, permisos Android, secretos y vulnerabilidades.

## Release/DevOps Agent
Mantiene CI, despliegue, backups, costes y rollback.

## Coordinación
El agente coordinador lee AGENTS.md y current-status.md, asigna tareas pequeñas, exige evidencia de tests y evita que agentes cambien decisiones protegidas sin aprobación.
